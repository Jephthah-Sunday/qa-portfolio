Mobile QA (Appium)

End-to-end mobile testing on Android/iOS with Appium and a device farm (CI-driven). Product names omitted for NDA compliance.

At-a-glance results

Manual regression

240m → 48m (−80%) via smoke tagging + parallel device runs.

Flake rate

10.7% → 1.9% (last 150 runs) using a11y IDs + deterministic waits.

P0/P1 escapes

2–6 → 0 across the last 2 releases with PR merge gates.

Scope & Context

  • Cross-platform app: onboarding → catalog → paywall/checkout → content access (with deep-links & offline).
  • Weekly releases; need fast, reliable PR signals and broader device/OS coverage.
  • 3rd-party SDKs (IAP/analytics/push) and entitlement sync were frequent sources of regressions.

Test Design

  • Journeys covered (smoke): login, onboarding, paywall, purchase, entitlement sync, deep-link open, offline access.
  • Tagging: @smoke, @regression, @payments, @offline, @deeplink.
  • Selectors: stable testID/accessibilityLabel on key elements for resilience.
  • Data strategy: seeded sandbox accounts; idempotent purchase teardown; isolated tenants/build variants.
  • Locales/timezones: data-driven sets (en-US, en-GB, fr-FR; UTC/GMT+1) to catch formatting & DST issues.

Device Coverage

  • Android: 12, 13 (Pixel 6/7 class + mid-range)
  • iOS: 16, 17 (iPhone 12/13/14)
  • Network conditioning: Offline / 3G profiles for resilience checks.
  • Orientation: portrait (smoke), landscape (select flows).

CI/CD Integration

  • PR gate: run @smoke on a device matrix via cloud (videos/screenshots uploaded).
  • Nightly: full regression incl. offline, deep-links, and purchase renewal; publish consolidated HTML report.
  • Artifacts: step-level screenshots, videos, logs (Appium server + device), and JUnit for quick triage.
Example CI matrix (pseudo-YAML) 
strategy:
  matrix:
    os: [android-13, android-12, ios-17, ios-16]
steps:
  - run: npm ci
  - run: npm run test:mobile -- --tags @smoke --os ${{ matrix.os }}
  - uses: actions/upload-artifact@v4
    with:
      name: mobile-${{ matrix.os }}-reports
      path: mobile/appium/reports/**
