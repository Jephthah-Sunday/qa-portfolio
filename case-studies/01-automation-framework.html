Web E2E Automation (Cypress & Playwright)

Reduced manual regression effort by creating a robust POM‑based suite, running in CI with flaky‑test control.

At A Glance Results

Regression runtime

150m → 28m (−81%) via tagging + parallel workers.

Flake rate

9.4% → 1.6% (last 200 runs) using stable selectors + quarantine.

P0 escapes

3 → 0 over 2 releases with PR smoke gates.

Context

  • SaaS web application with weekly releases; critical flows: auth, catalog, cart/checkout.
  • Requirement: a dependable, fast smoke gate on PR + deeper nightly regression runs.
  • Approach: maintain **parity** between Cypress and Playwright so teams can compare DX/traceability, and avoid single-tool lock-in.

Repo root: Automation-Scripts

Goals & Risks

  • Cut regression time to <30 minutes with selective tags + parallelization.
  • Stabilize smoke to ≤2% flake and enforce it as a required PR check.
  • Improve observability with videos, screenshots, and HTML/trace reports in CI.

Key risks: brittle selectors, async race conditions, unstable test data, third-party variability.

Architecture & Test Design

Shared strategy

  • POM for Login, Inventory, Cart/Checkout, Profile; shared helpers + custom commands/utilities.
  • Tagging: @smoke, @regression, @auth, @checkout for selective runs.
  • Data strategy: seeded users, idempotent teardown, unique fixtures per run.
  • Network control: stub external providers in PR runs; exercise live endpoints in nightly.

CI/CD Integration

  • GitHub Actions matrix across {framework: cypress, playwright} × {browser: Chrome, Firefox}.
  • Artifacts: Cypress videos/screens + Mochawesome/Allure; Playwright HTML + traces.
  • Budgets: fail PR if smoke duration or flake threshold is exceeded.
CI workflow in github/workflows/ci.yml 
name: CI
on:
  push: { branches: [Master] }
  pull_request:
permissions: { contents: read }
jobs:
  e2e:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        framework: [cypress, playwright]
        browser: [chrome, firefox]
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with: { node-version: 18 }
      - name: Install deps
        run: npm ci
      - name: Run ${{ matrix.framework }} on ${{ matrix.browser }}
        env:
          BROWSER: ${{ matrix.browser }}
        run: |
          if [ "${{ matrix.framework }}" = "cypress" ]; then
            npm run test:cypress
          else
            npm run test:playwright
          fi
      - name: Upload reports
        uses: actions/upload-artifact@v4
        with:
          name: ${{ matrix.framework }}-${{ matrix.browser }}-reports
          path: |
            packages/e2e-cypress/mochawesome-report/**
            packages/e2e-cypress/allure-results/**
            packages/e2e-playwright/playwright-report/**

Flakiness Control

  • Stable data-test selectors & deterministic waits (no fixed sleeps).
  • Retries only on idempotent steps; quarantine tag/list for known external instability.
  • Periodic selector audits and CI trend monitoring to keep the suite healthy.
