## How to use
1. Replace the markdown templates in `case-studies/` with your real projects and artifacts (plans, reports, videos, dashboards).
2. Open `index.html` and adjust skills, links, and wording.
3. Add screenshots to `assets/` and link them in your case studies.
4. Host the site:
   - **GitHub Pages:** Put files in `main` or `gh-pages` branch and enable Pages.
   - **Netlify:** Drag‑and‑drop the folder or connect your repo.
5. Keep a consistent story: goals → approach → evidence → measurable results.

## Tip: What to show
- Before/after metrics (e.g., regression runtime, pass rates, Lighthouse, Core Web Vitals).
- Test architecture diagrams (POM, fixtures, data strategies).
- CI pipelines and flakiness strategies.
- Bug reports with impact and how fixes were verified.
